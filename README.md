# YouTube-Video-Notes-Generator
A Python-based application that converts YouTube videos into structured notes. It uses Whisper AI to process audio and generate English notes, with options for Hindi and Kannada translation and PDF downloads.

# Features

YouTube Audio Extraction: Downloads audio from YouTube videos.
Speech-to-Text: Uses OpenAI Whisper to convert speech into English text.
Notes Generation: Organizes the extracted text into summaries and key points.
Multilingual Support: Provides options to translate notes into Hindi and Kannada.
PDF Download: Allows users to download generated notes as PDF files.
Interactive Interface: Built with Streamlit for a simple and user-friendly experience.
